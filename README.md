# Глобус — Flappy

Игра в духе Flappy Bird: вместо птицы пиксельное лицо. Открывается меню с вопросом
и кнопкой «Да», дальше нажатие — взмах и «ам!», а удар о трубу или землю — крик
«Ебаный в рот!». Чистые HTML, CSS и JS: без сборщика, без npm и без внешних файлов.

## Запуск

```bash
python3 -m http.server 8123
```

Затем http://localhost:8123. С телефона — по адресу компьютера в локальной сети.
Управление: пробел, ↑, Enter или клик/тап; `M` или значок динамика — звук. В меню
работает только кнопка «Да» (или пробел/Enter).

Двойной клик по `index.html` тоже должен работать (скрипты классические, звук
через `<audio>`), но в сборке проверялось только через сервер.

## Заменить фото лица

1. Положите фото в `source/face.jpg` — анфас, крупно, ровный свет.
2. Рядом создайте `source/face.json` — контур головы и точки лица. Все числа в
   пикселях исходного фото (координаты удобно смотреть в любом просмотрщике):

```json
{
  "outline": [[470, 92], [600, 105], [692, 160], "..."],
  "eyes": [[355, 588], [640, 568]],
  "mouth": [500, 878]
}
```

   `outline` — точки по контуру головы по часовой стрелке (хватит 25–35): по нему
   голова вырезается без круга, видны скулы, челюсть и уши. `eyes` — центры глаз
   (для плача), `mouth` — линия губ: по ней голова режется, и у неё отвисает
   челюсть, когда рот открывается.
3. Запустите (нужен Pillow):

```bash
python3 tools/pixelate.py
```

Без `face.json` голова вырезается овалом по центру кадра (`--face-box x,y,w,h`
задаёт область овала), а глаза и рот ставятся по типичным пропорциям.
`--height 40` делает спрайт крупнее (по умолчанию 34 пикселя в высоту).

Если положить ещё и `source/face-cry.jpg`, при ударе будет показано оно, а не
рисованный плач.

## Заменить трубы

Без фото игра рисует трубы сама: розовые, гладкие, с большой круглой шапкой и
чёрточкой по центру, а между ними по очереди идут бутылки пива. Чтобы текстурировать их фотографиями, положите
`source/pipe.jpg` (можно `pipe-2.jpg` и т. д. — тогда они чередуются) и запустите
`python3 tools/pixelate.py`. Текстура должна идти вдоль трубы; если труба на фото
лежит горизонтально — добавьте `--rotate`.

## Заменить голоса

Положите свои записи в `assets/audio` как `cry.mp3` (крик при ударе) и `am.mp3`
(«ам» на каждый взмах). Они имеют приоритет над сгенерированными `cry.m4a` и
`am.m4a`. Пока `mp3` нет, в консоли браузера будут два 404 на них — так и должно быть.

Сгенерировать запасные голоса заново (macOS, голос Milena):

```bash
zsh tools/make-voices.sh
```

## Музыка

Сейчас музыка выключена, файла `assets/audio/music.m4a` в проекте нет. Чтобы вернуть
фоновую музыку: вырежьте кусок песни (нужен macOS)

```bash
python3 tools/make-music.py "/путь/к/песне.mp3" --start 0 --length 60
```

и добавьте вызов `Sound.music(true);` в конец `start()` в `assets/js/game.js`. Музыка играет
по кругу; браузеры не включают звук до первого касания, так что стартует она с ним.

## Звук на телефоне

Голоса играют через WebAudio. iPhone разрешает звук только после отпускания пальца
(`pointerup`, `touchend`, `click`), поэтому игра «будит» звук по ним, а не по нажатию.
Для голосов `.mp3` и `.m4a` загружаются через `fetch`, поэтому по `file://` (двойной
клик) они играют запасным путём через `<audio>`. Для отладки в консоли есть
`Sound.info()`: состояние контекста и список загруженных голосов.

## Баланс

В начале `assets/js/game.js`: гравитация и импульс взмаха (`GRAVITY`, `FLAP_V`),
скорость мира `SPEED`, просвет между трубами `GAP`, расстояние между ними `SPACING`,
хитбокс `HIT` (два круга по форме головы), насколько широко открывается рот `OPEN`.
Название игры — `TITLE`, вопрос в меню — `ASK`, надпись при ударе — `FAIL`. Размеры спрайта трубы (`PIPE_W`, `CAP_W`,
`CAP_H`, `TILE_H`) должны совпадать с `tools/pixelate.py`.

Просвет подобран так, чтобы свободный зазор был примерно вдвое больше подъёма
одного взмаха (сейчас `GAP` 86, `SPACING` 92). Если будете менять `GAP`, `FLAP_V` или высоту спрайта, держите это
соотношение, иначе игра станет либо неиграбельной, либо скучной.

Для отладки из консоли есть `__game` (`step(n)`, `die()`, `state`, `score`) и
автопилот: `__bot = true`.

## Что где

```
index.html          страница с холстом
assets/js/game.js   игра: физика, трубы, столкновения, отрисовка, плач
assets/js/audio.js  звуки: голоса героя и короткие эффекты
assets/js/font.js   пиксельный шрифт 5×7 (кириллица, цифры)
assets/js/sprites.js  манифест спрайтов — создаёт tools/pixelate.py
assets/*.png        спрайты: face.png, pipe-N.png
assets/audio        cry.m4a, am.m4a (и свои cry.mp3, am.mp3)
source/             исходные фото, в git не попадают
tools/              pixelate.py, make-voices.sh, make-music.py
```
